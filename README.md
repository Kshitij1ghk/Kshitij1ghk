## 🚀 Featured Projects

### 🤖 **AI & GenAI Projects**

#### 🧠 Business RAG Assistant

* **[Business-RAG-Assistant](https://github.com/Kshitij1ghk/business-rag-assistant)** - End-to-end Retrieval-Augmented Generation (RAG) system for answering questions over internal policy documents.
* Built using **Python, FastAPI, Qdrant, FastEmbed, and Gemini**.
* Implements document chunking, embeddings, vector search, grounded answers, source citations, similarity scores, and confidence indicators.
* Includes RAG safety mechanisms such as similarity thresholds and protection against prompt injection.
* Includes **16 passing pytest tests** and retrieval diagnostics for threshold tuning.

#### 🔧 MCP-Powered Developer Assistant

* **[MCP-Powered-Developer-Assistant](https://github.com/Kshitij1ghk/MCP-Powered-Developer-Assistant)** - AI-powered developer assistant built using **Python and Model Context Protocol (MCP)**.
* Connects separate code, GitHub, and testing MCP servers into multi-step agent workflows.
* Supports bug localization, symbol inspection, issue triage, patch generation, and validation.
* Implements **Python AST parsing, path-jailing, path-traversal prevention, diff-based patch generation, and sandboxed pytest execution**.
* Includes interactive **human-in-the-loop approval gates** before code changes are written.
* Includes **16 unit and integration tests** covering the code, patching, GitHub, and agent-flow layers.

#### 🔮 Asterion Astrologer

* **[Asterion Astrologer](https://asterion-gamma.vercel.app/)** - Full-stack AI astrology web application.
* Built using **Python, Flask, Groq LLM API, Whisper, and Vercel**.
* Generates Vedic and KP birth charts with planetary positions, Vimshottari Dasha periods, Star Lords / Sub Lords analysis, and daily horoscopes.
* Includes a conversational AI assistant powered by Groq-hosted LLMs with conversation memory and quick-action prompts.
* Supports **Whisper speech-to-text and text-to-speech** for Hinglish and English voice interaction.
* Includes birthplace search using OpenStreetMap and is deployed on Vercel.
